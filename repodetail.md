# ExamPortal Repository Details

Welcome to the ExamPortal repository!

## Repository Information
- **Project Name:** ExamPortal
- **GitHub Repository Link:** [https://github.com/PrincePanara/Examportal](https://github.com/PrincePanara/Examportal)

## Project Overview
This project is an advanced, modern web application for an Exam Portal. It is built using:
- **Frontend Framework:** React with Vite
- **Database / Backend:** Firebase (Firestore)
- **Styling:** Tailwind CSS

## Getting Started
To run this project locally, simply clone the repository, install the dependencies, and start the development server:

```bash
git clone https://github.com/PrincePanara/Examportal.git
cd ExamPortel
npm install
npm run dev
```
